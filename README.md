# 🚀 Featured Project

## 💊 MedExpiry Pro

> **WhatsApp-based SaaS helping medical stores reduce losses from expired medicine inventory.**

<p>
  <img src="https://img.shields.io/badge/PERN-Stack-2563EB?style=flat-square" />
  <img src="https://img.shields.io/badge/WhatsApp-Meta_API-25D366?style=flat-square&logo=whatsapp" />
  <img src="https://img.shields.io/badge/AI-Groq-F55036?style=flat-square" />
  <img src="https://img.shields.io/badge/OCR-Document_Processing-7C3AED?style=flat-square" />
  <img src="https://img.shields.io/badge/Status-LIVE-22C55E?style=flat-square" />
</p>

MedExpiry allows medical store owners to manage medicine expiry without learning complicated inventory software.

### ⚡ What I built

- 📸 OCR-based medicine/invoice extraction
- 🤖 AI-assisted medicine data processing
- 💬 WhatsApp-based interaction using Meta API
- 🔐 Authentication & user management with Supabase
- ⏰ Automated medicine expiry reminders
- 📊 Inventory dashboard
- 🔄 Automated workflow processing
- ☁️ Production deployment & infrastructure

### 🎯 Problem it solves

Pharmacies often lose money because medicines remain unnoticed until they expire and can no longer be sold or returned.

MedExpiry helps identify those medicines **before they become financial losses**.
